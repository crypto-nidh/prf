# Hazel Portfolio

A premium, interactive web application security portfolio built with React, Three.js, React Three Fiber, and Framer Motion.

## Features
- **3D Cinematic Background**: Interactive spline camera flight path with instanced mesh debris and high-end post-processing (Bloom, Chromatic Aberration).
- **Hacker Aesthetic**: Raw, brutalist terminal styling using `Share Tech Mono`, glitch effects, and sharp glassmorphic panels.
- **Dynamic Theming**: Easily switch between a dark cyberpunk theme and a high-contrast vaporwave/cyber-pop light theme.
- **Performance Optimized**: Uses instancing for 3,000+ 3D nodes to maintain 60FPS on the web.

## Tech Stack
- React
- Vite
- Three.js & @react-three/fiber
- Framer Motion
- Lenis (Smooth Scrolling)
